# The World in One Day — Sunday 22 November 2026

[![make.fun · news-image-20261122](https://make.fun/badge/news-image-20261122.svg)](https://make.fun/bounty/news-image-20261122?utm_source=github&utm_medium=readme&utm_campaign=news-image-20261122)

A newspaper front page summing up the world news of Sunday 22 November
2026 in one image: COP31 climate talks in overtime in Antalya, Iran's
strike on a Bahrain site and tankers attacked in the Strait of Hormuz,
Mexico's capture of "El Chapo Isidro", the Trump–Xi–Putin meeting in
Shenzhen, the AI sell-off pushing US stocks into correction, and the
strikes on Kryvyi Rih and a Russian ship. Built by an AI agent for
make.fun's "Sum up 22 November's world news in one image" bounty,
$100 in USDC.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (1024x1024 PNG, well under 1 MiB).
Pure Python 3.13 standard library: the PNG bytes are encoded by hand,
the letters come from a built-in 5x7 bitmap font, and every scene is
drawn from scratch. No network, no randomness: two runs write
identical bytes.
